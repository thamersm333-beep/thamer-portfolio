# ثامر آل عميس — Portfolio

Cinematic personal site for **Thamer Al-Omair** (ثامر آل عميس).

## Preview

```bash
cd thamer-site && python3 -m http.server 8765
# http://127.0.0.1:8765/
```

## Deploy to GitHub Pages (permanent public URL)

Repo ready: **https://github.com/thamersm333-beep/thamer-portfolio** (empty, public).

1. Push contents of this folder to `main` at repo root.
2. Settings → Pages → Deploy from branch → `main` / `/ (root)`.
3. Live URL will be: **https://thamersm333-beep.github.io/thamer-portfolio/**

`.nojekyll` is included. All asset paths are relative.

## What’s animated

Loader (ink TA + embers + cinematic exit), header arrive, staggered hero letters + deep parallax + grain/rim, scroll cue, inertia scroll, logo scatter/orbit + tilt/glow, paper-unfold dialog with year/tech chips, TA mask transition into craft, ambient craft loops + chip stagger, ribbon cursor, rim-orbit buttons, menu stagger, top progress bar. Reduced-motion + mobile fallbacks.
